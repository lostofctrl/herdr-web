# File browser port: parity and acceptance matrix

This is an inventory of the `/home/plugi/pi-web` checkout examined for the port. Acceptance checks below are requirements, not claims that the port or tests already exist. Security restrictions take precedence over reference behavior.

| Feature | Reference behavior | Acceptance checks for herdr-web |
| --- | --- | --- |
| Local tabs | `components/spaces/SpacesToolWindow.tsx` mounts `FileExplorer`; file tab state retains viewer settings. Pi Web uses session storage. | Create, select, close and reload multiple browser-owned tabs without Herdr commands or selection synchronization; each remains bound to its bridge and root, including after global host changes. Explain unavailable, older, removed or changed bridges/roots. |
| Tree and navigation | `components/FileExplorer.tsx` lazily lists directories, expands, selects, reveals, changes root and refreshes. Entries are directories-first, then alphabetic. | Browse nested folders on desktop and mobile, expand/collapse and refresh; only the operator-configured root and safe relative symlinks are accessible. Reject absolute links, escapes and failed resolutions. |
| Listing exclusions | File route uses fixed name/suffix exclusions such as `.git`, `node_modules`, `dist`, `build`, `target`, `vendor` and `.pyc`, not `.gitignore`. | Verify excluded names and deterministic ordering; ensure exclusions are not described as an access-control boundary. |
| Filename search | `/api/file-index`: 150 ms debounce; Git index honors tracked files and ignored untracked files. Non-Git walk uses a fixed skip list, depth 8 and 50,000 files. | Search known tracked, ignored and nested fixtures; assert result bounds and show truncation/errors. Git-aware enumeration must be unavailable when safe Git isolation is unavailable, rather than silently bypassing ignore rules after Git errors. |
| Content search | Separate opt-in universal search (`PI_WEB_FILE_CONTENT_SEARCH=1`), with literal case-insensitive matching, 4,000 files, 2 MiB/file, 50 results/page and 2.5-second budget; excludes common secret names and generated/binary content. | Exercise bounded case-insensitive search, pagination, exclusions, skipped paths and truncation where this separate behavior is exposed; name-based secret exclusions must not be represented as secrecy guarantees. |
| Create, rename, delete, copy | Explorer validates names, confirms deletion, rejects collisions, recursively deletes/copies and chooses copy suffixes. Root deletion is forbidden. | Create and rename without overwriting; reject invalid names, root deletion, recursive self-copy and traversal; copy, delete and confirm safely; preserve dirty drafts after rename or deletion. Include symlink and parent replacement races. |
| Upload and download | Upload offers error/overwrite/skip; per-file limit 25 MiB and aggregate 100 MiB. Download and media support streaming/ranges. | Verify collision choices, limits, interrupted transfers, containment and safe download headers; exercise range reads without unbounded buffering. |
| Watch and reconnect | Individual file watches use parent-directory SSE and resynchronize on connection/change; active editing is not overwritten. Tree refreshes on its own actions, not a directory watch. | Verify replacement/deletion, watch overflow, disconnect/reconnect and full resynchronization; keep dirty draft on every external event and show the conflict. |
| Text viewing and editing | Source, preview and Git diff; text chunks are 256 KiB, editing requires the full file. Syntax highlighting falls back above 1,000 lines or 1 MiB. Editor preserves draft on failed save and warns on dirty cancellation/unload. | Open and load large text, toggle wrap, select lines, edit and save; preserve draft on errors, conflicts, rename, deletion and disconnect. Two bridge clients and external writers must exercise revision checking and the documented non-atomic external-writer limit. |
| Draft and viewer restoration | Viewer mode, wrap and scroll state survive a tab remount; Pi Web does not persist unsaved editor drafts. | Recover drafts after reload within the same live bridge/root binding. After a bridge restart, quarantine old drafts until the user confirms the current root once, because root continuity across downtime cannot always be proved. Warn about local sensitive content, closing and reload; offer discard; surface quota/storage failure while retaining in-memory draft. Never silently restore into a changed root or host. |
| Markdown and HTML | Markdown supports frontmatter, GFM, math, Mermaid, code and local links; HTML uses a script-enabled sandbox. Markdown/HTML preview by default unless restored state or line target says otherwise. | Test supported formatting, default/restored modes and local links. Render untrusted content inertly or in a restrictive sandbox without application-origin or bridge API access; do not port script execution or unrestricted external resources. |
| Image, audio, video | Image: png, jpg/jpeg, gif, webp, svg, bmp, ico, avif. Audio: mp3, wav, ogg/oga, opus, m4a, aac, flac, weba. Video: mp4/m4v, webm, mov, ogv. Native playback depends on browser codecs. Image preview limit 10 MiB. | Exercise each type's dispatch, representative safe image/audio/video playback, limits, unsupported codecs and active SVG payloads; no executable content reaches the application origin. |
| Documents | PDF embedded; DOCX converted via Mammoth, with 10 MiB limit and sandbox/CSP. | Test PDF and DOCX, size/error states and hostile content; enforce sandbox/CSP, safe resource handling and no bridge access. Downloads use `nosniff` and safe attachment behavior. |
| Git status and diffs | Scoped status with additions/deletions; combined, staged and unstaged diffs, using bounded Git invocations. | Verify statuses/diffs for authorized repositories and metadata roots, malicious config and metadata escapes, resource bounds and isolation. Clearly report Git unavailable on platforms without tested enforcement; do not execute unsafe Git as a fallback. |
| Pi mentions | File mention and selected-line mention, including Ctrl/Cmd+I, insert into Pi Web chat; mobile closes panels. | Offer an explicit same-bridge Pi Pane chooser with last eligible default. Validate connection and pane at action time; correctly encode path and lines independent of pane cwd, preserve existing Composer draft, never submit, and reject stale/cross-host targets. |
| Accessibility and mobile | F2, Delete, copy/paste and Ctrl/Cmd+I shortcuts; compact viewer at ≤640px and ≤380px; full-width mobile panel. | Keyboard-operate explorer, dialogs and editor; verify labels, focus, error announcements and desktop/mobile layouts, plus real browser acceptance. |

## Integration and restrictions

- Herdr's existing tabs and `selectTab`/`openPane` are shared navigation; the file surface must not use them to create or select a Herdr tab. `web/src/App.tsx` owns navigation; `web/src/bridge.tsx` owns profiles, connection keys and capability parsing. A profile ID survives URL edits, so it is not by itself a safe binding.
- `web/src/pi/sidepanel/piComposerInsert.ts` inserts into a Composer draft without sending; mounted Composer can reject an insertion during delivery/recovery without reporting it. The port must handle that case rather than claim insertion succeeded.
- The reference grants some session-referenced files outside configured roots, performs path checks before later opens, saves without revision checks, and permits scripts in HTML previews. None of those behaviors is authorized for this port.
- Host/origin checks are not authentication. Root access is disabled unless an operator configures it; every allowed client then has root read/write authority. Root-pinned descriptors retain authority to an already-open directory moved by another local process; hard-link provenance is unknowable. External non-cooperating writers can race a check-and-rename save.
- Source entry points: `/home/plugi/pi-web/components/FileExplorer.tsx`, `/home/plugi/pi-web/components/FileViewer.tsx`, `/home/plugi/pi-web/components/file-viewer/`, `/home/plugi/pi-web/components/file-tab-state.ts`, `/home/plugi/pi-web/app/api/files/[...path]/route.ts`, `/home/plugi/pi-web/app/api/file-index/route.ts`, and `/home/plugi/pi-web/lib/file-types.ts`. Reference tests include `FileExplorer.test.mjs`, `FileViewer*.test.mjs`, file route tests and `e2e/file-panel.mjs`.

## Implementation status

Updated as the port lands. "Verified" means an automated test plus, where marked, a real browser run
against a live bridge (`Localdev` + `playwright-cli`, disposable Herdr workspace, temporary root).

| Area | Status | Evidence |
| --- | --- | --- |
| Confined listing/read/save | Verified | `bridge/src/file_root.rs`, `bridge/src/file_root/file_read.rs`, `bridge/src/file_root/file_read/file_save.rs`; independent static review found no escape in 3,000 swap iterations. |
| Create, rename, delete | Verified | `bridge/src/file_mutations.rs`, `bridge/src/file_service.rs`; browser run created a file and a directory, renamed an open file, deleted an entry. Created entries follow the process umask (0644/0755 by default), matching the reference. |

Copying a single open file is wired in the workspace; tree-level copy/delete of directories is not yet exposed in the explorer. Browser acceptance for the copy flow is blocked in this environment (no Chrome channel installed, the Localdev run exited and the fallback browser session timed out), so copy is covered only by unit and contract tests. |
| Route and policy | Verified | `bridge/src/web_bridge/file_http.rs`, `bridge/src/web_bridge/file_route_tests.rs`; 404 when no root, 403 for foreign host/origin, 413/503 before reading the body. |
